
# Telco Customer Churn Dashboard

An interactive dashboard that analyzes why customers leave a telecom company and which customer groups are most at risk.

🔗 **Live Dashboard:** index.html

## Overview
This project analyzes **7,043 Telco customers** to understand churn patterns. About **26.5% of customers (1,869)** churned. The dashboard lets you click any chart or use the filters to cross-filter every page.

## Dashboard Pages
- **Overview:** Retained vs churned, churn by contract, internet service and tenure, top 10 churn reasons
- **Demographics:** Churn by gender, senior citizen, partner and dependents
- **Services:** Phone, multiple lines, online security, backup, device protection, tech support, streaming
- **Billing:** Contract, payment method, paperless billing, CLTV and monthly charges
- **Geography:** Customer map by location and top cities

## Key Insights
- **Month-to-month contracts** have the highest churn (~42.7%), vs only ~2.8% for two-year contracts
- **Fiber optic** customers churn the most (~41.9%)
- **Electronic check** users churn at ~45.3%, far above automatic payment methods (~15-17%)
- Most churn reasons are linked to **competitors** (better offers, speeds, data and devices)

## Features
- Filters for 14 fields (contract, tenure, city, payment method, etc.)
- Click-to-filter charts across all pages
- KPI cards that update with every filter
- Works on desktop and mobile

## Tech Used
- HTML, JavaScript, Chart.js
